\section{Deskripsi Sistem}

Sistem yang dikembangkan dalam kerja praktik ini adalah sebuah kerangka kerja \textit{fault tolerance} untuk pemrosesan citra medis, khususnya MRI otak. Sistem ini dirancang untuk melakukan mitigasi dampak negatif dari artefak gerak (\textit{motion artifacts}) sebelum citra diproses lebih lanjut oleh sistem lanjutan \textit{image captioning}. Secara garis besar, sistem terdiri dari tiga komponen utama yang saling terintegrasi:

\begin{enumerate}[nolistsep]
	\item \textbf{Modul simulasi data} yang bertugas untuk menghasilkan dataset sintetis untuk menyimulasikan artefak gerak yang terjadi di dunia nyata.
	
	\item \textbf{Modul klasifikasi artefak} yang bertugas mendeteksi jenis artefak gerak dengan empat kelas klasifikasi yaitu translasi horizontal, translasi vertikal, rotasi, dan gambar bersih pada citra.
	
	\item \textbf{Modul koreksi citra} yang bertugas merekonstruksi citra dengan artefak menjadi citra bersih.
\end{enumerate}

\subsection{Desain Pembuatan Dataset Simulasi}

Untuk melatih model koreksi citra dengan Pix2Pix, diperlukan pasangan data citra bersih dan artefak. Sistem ini menggunakan pendekatan simulasi berbasis domain frekuensi (\textit{k-space}) untuk melakukan simulasi artefak gerak sesuai dengan kondisi pada dunia nyata. Proses pembuatan dataset latih ditunjukkan pada Gambar \ref{fig:flowchart-dataset}.

\begin{figure}[H]
	\includegraphics[width=\linewidth]{gambar/flowchart-dataset.png}
	\caption{Diagram Alur Pembuatan Dataset}
	\label{fig:flowchart-dataset}
\end{figure}

Secara umum, proses simulasi artefak terdiri dari tiga bagian, yaitu:

\begin{enumerate}[nolistsep]
	\item Transformasi citra bersih ke \textit{k-space} domain frekuensi menggunakan \textit{Fast Fourier Transform} (FFT).
	\item Simulasi artefak dengan menggabungkan (\textit{splicing}) garis-garis frekuensi dari citra diam dan citra yang dilakukan translasi atau rotasi. Hal ini meniru inkonsistensi fase yang terjadi ketika pasien bergerak selama pemindaian MRI.
	\item Rekonstruksi citra dari data \textit{corrupt k-space} dikembalikan ke domain spasial menggunakan \textit{Inverse FFT} untuk menghasilkan artefak \textit{ghosting} dan \textit{streaking} yang realistis.
\end{enumerate}

\subsection{Desain Modul Klasifikasi Artefak}

Modul klasifikasi dirancang menggunakan pendekatan \textit{Transfer Learning} dari model \textit{pre-trained} untuk mengklasifikasikan empat kelas artefak citra, yaitu bersih, \textit{horizontal translation}, \textit{vertical translation}, dan rotasi. Proses klasifikasi secara detail dapat dilihat pada Gambar \ref{fig:flowchart-klasifikasi}.

	\caption{Diagram Alur Modul Klasifikasi}
	\label{fig:flowchart-klasifikasi}

Desain modul klasifikasi ini mengeksplorasi dua arsitektur \textit{deep learning} untuk tugas \textit{computer vision}, yaitu \textit{Convolutional Neural Network} (CNN) menggunakan model ResNet, DenseNet, dan EfficientNet serta arsitektur Transformer menggunakan \textit{Vision Transformer} (ViT) dan Swin Transformer. Lapisan akhir setiap model dimodifikasi menjadi \textit{classification head} untuk menghasilkan probabilitas bagi empat kelas target.

\subsection{Desain Modul Koreksi Citra}

Modul koreksi dirancang untuk tugas translasi gambar ke gambar (\textit{image-to-image translation}). Arsitektur yang digunakan adalah Pix2Pix \textit{Conditional GAN} untuk merekonstruksi gambar bersih dari gambar dengan artefak. Arsitektur modul koreksi dapat dilihat pada Gambar \ref{fig:flowchart-koreksi}.

\begin{figure}[H]
	\centering
	\includegraphics[width=0.5\linewidth]{gambar/flowchart-koreksi.png}
	\caption{Diagram Alur Modul Koreksi Citra}
	\label{fig:flowchart-koreksi}
\end{figure}

Pix2Pix terdiri dari dua komponen yang saling berkompetisi:

\begin{enumerate}[nolistsep]
	\item \textit{Generator} berbasis U-Net yang bertugas menerima input citra dengan artefak dan menghasilkan citra bersih. Arsitektur U-Net digunakan karena adanya \textit{skip connections} yang memungkinkan informasi detail struktur otak dari input tetap terjaga hingga \textit{output}.
	\item \textit{Discriminator} berbasis \textit{convolutional PatchGAN} yang bertugas membedakan antara citra bersih asli dan citra hasil rekonstruksi \textit{Generator}. PatchGAN bekerja dengan menilai realisme citra pada level \textit{patch} lokal yang efektif untuk menghasilkan tekstur yang tajam.
\end{enumerate}

def load_and_resize_nifti(nifti_path):
	try:
		img_nii = nib.load(nifti_path)
		img_data = img_nii.get_fdata()
		
		# Ambil slice tengah
		slice_idx = img_data.shape[2] // 2
		slice_2d = img_data[:, :, slice_idx]
		slice_2d = np.nan_to_num(slice_2d)
		
		# Normalisasi ke range [0, 255]
		if slice_2d.max() > slice_2d.min():
			slice_2d = (slice_2d - slice_2d.min()) / (slice_2d.max() - slice_2d.min()) * 255.0
		
		# Konversi ke uint8 sebelum resizing ke PIL
		slice_2d_uint8 = slice_2d.astype(np.uint8)
		pil_img = Image.fromarray(slice_2d_uint8)
		pil_img = pil_img.resize((IMG_WIDTH, IMG_HEIGHT), Image.NEAREST)
		return np.array(pil_img).astype(np.float32)
	
	except (nib.filebasedimages.ImageFileError, FileNotFoundError):
		return None
	\end{lstlisting}

\subsubsection{Simulasi Artefak}

\begin{adjustwidth}{1em}{0pt}
	\begin{sloppypar}
		\hspace{\parindent}Inti dari simulasi citra MRI terdapat pada fungsi \texttt{apply\_kspace\_corruption} yang ditunjukkan pada Kode \ref{lst:simcorrupt}.
	\end{sloppypar}
	\begin{lstlisting}[
		language=python,
		label={lst:simcorrupt},
		caption={Fungsi \textit{Image Corruption}},
		xleftmargin=1em
		]
def apply_kspace_corruption(clean_image_2d, moved_image_2d, corruption_percent):
	
	# 1. Konversi ke K-Space (FFT)
	kspace_clean = np.fft.fft2(clean_image_2d.astype(np.complex64))
	kspace_moved = np.fft.fft2(moved_image_2d.astype(np.complex64))
		
	# 2. Buat corrupted k-space
	height, width = clean_image_2d.shape
	
	corruption_lines = int(height * corruption_percent)
	if corruption_lines >= height:
		corruption_lines = height - 1
	if corruption_lines <= 0:
		corruption_lines = 1
	
	start_line = np.random.randint(0, height - corruption_lines)
	end_line = start_line + corruption_lines
	
	mask_line = np.concatenate([
		np.ones(start_line, dtype=bool),
		np.zeros(corruption_lines, dtype=bool),
		np.ones(height - end_line, dtype=bool)
		], axis=0)
	mask = np.tile(mask_line[:, np.newaxis], [1, width])
	
	kspace_corrupted = np.where(mask, kspace_clean, kspace_moved)
	
	# 3. Konversi balik ke gambar (IFFT)
	corrupted_image_complex = np.fft.ifft2(kspace_corrupted)
	corrupted_image_abs = np.abs(corrupted_image_complex).astype(np.float32)
	
	# 4. Normalisasi ke 0-255 uint8 untuk disimpan sebagai gambar PIL
	if corrupted_image_abs.max() > corrupted_image_abs.min():
		corrupted_image_abs = (corrupted_image_abs - corrupted_image_abs.min()) / (corrupted_image_abs.max() - corrupted_image_abs.min()) * 255.0
	
	# 5. Tumpuk 3 channel untuk konsistensi
	return np.stack([corrupted_image_abs] * 3, axis=-1).astype(np.uint8)
	\end{lstlisting}
	
	Fungsi ini menerima citra asli dan citra yang telah dirotasi atau ditranslasi. Kedua citra dikonversi ke domain frekuensi (\textit{k-space}) menggunakan FFT. Kemudian, sebagian garis frekuensi citra asli diganti dengan garis frekuensi dari citra yang digerakkan untuk mensimulasikan inkonsistensi data saat pasien bergerak.
\end{adjustwidth}

\subsection{Implementasi Modul Koreksi Citra}

Implementasi modul koreksi bertujuan untuk membangun sistem restorasi citra yang dapat mengoreksi \textit{motion artifact} dan menghasilkan kembali citra MRI yang bersih. Implementasi modul menggunakan \textit{Generative Adversarial Network} (GAN) dengan arsitektur Pix2Pix yang dirancang khusus untuk tugas \textit{image-to-image translation}. Arsitektur ini terdiri dari \textit{Generator} U-Net dan \textit{Discriminator} PatchGAN. Implementasi ini dilakukan menggunakan \textit{library} TensorFlow dan Keras.

\subsubsection{Arsitektur \textit{Generator}}

\begin{adjustwidth}{1em}{0pt}
	\hspace{\parindent}Komponen Generator pada Pix2Pix bertugas menerima citra dengan artefak dan menghasilkan citra sintetis yang bersih. Arsitektur yang digunakan adalah U-Net yang dimodifikasi. Struktur ini terdiri dari dua bagian utama:
	\begin{enumerate}[nosep]
		\item \textbf{\textit{Encoder (Downsampling)}}: Serangkaian lapisan konvolusi yang secara bertahap mengurangi resolusi spasial citra, semisal dari $256 \times 256$ menjadi $1 \times 1$ untuk mengekstraksi fitur konteks tingkat tinggi.
		
		\item \textbf{\textit{Decoder (Upsampling):}} Serangkaian lapisan konvolusi transposisi (\textit{Transpose Convolution}) yang mengembalikan resolusi citra ke ukuran aslinya.
	\end{enumerate}
	
	Implementasi \textit{Generator} ditunjukkan pada Kode \ref{lst:generatorimpl}.
	
	\begin{lstlisting}[
		language=python,
		label={lst:generatorimpl},
		caption={Implementasi Generator U-Net},
		xleftmargin=1em
		]
def Generator():
	inputs = tf.keras.layers.Input(shape=[256, 256, 3])
	down_stack = [
		downsample(64, 4, apply_batchnorm=False),
		downsample(128, 4),
		downsample(256, 4),
		downsample(512, 4),
		downsample(512, 4),
		downsample(512, 4),
		downsample(512, 4),
		downsample(512, 4),
	]
	
	up_stack = [
		upsample(512, 4, apply_dropout=True),
		upsample(512, 4, apply_dropout=True),
		upsample(512, 4, apply_dropout=True),
		upsample(512, 4),
		upsample(256, 4),
		upsample(128, 4),
		upsample(64, 4),
	]
	
	initializer = tf.random_normal_initializer(0., 0.02)
	last = tf.keras.layers.Conv2DTranspose(3, 4, strides=2, padding='same', kernel_initializer=initializer, activation='tanh')
	x = inputs
	
	skips = []
	for down in down_stack:
		x = down(x)
		skips.append(x)
	
	skips = reversed(skips[:-1])
	
	for up, skip in zip(up_stack, skips):
		x = up(x)
		x = tf.keras.layers.Concatenate()([x, skip])
	
	x = last(x)
	return tf.keras.Model(inputs=inputs, outputs=x)
	\end{lstlisting}
	
	Fitur kunci dari implementasi ini adalah penggunaan \textit{skip connections}. Lapisan ini menghubungkan output dari lapisan \textit{encoder} langsung ke lapisan \textit{decoder} yang bersesuaian, misalnya lapisan pertama encoder ke lapisan terakhir decoder. Mekanisme ini memungkinkan informasi detail spasial frekuensi rendah seperti tepi jaringan otak dan pembuluh darah untuk melewati \textit{bottleneck} dan dipulihkan dengan akurat di \textit{output} untuk mencegah hasil yang buram.
\end{adjustwidth}

\subsubsection{Arsitektur \textit{Discriminator}}

\begin{adjustwidth}{1em}{0pt}
	\hspace{\parindent}Komponen \textit{Discriminator} bertugas membedakan citra bersih (\textit{ground truth}) dengan citra hasil rekonstruksi \textit{Generator}. Implementasi ini menggunakan arsitektur PatchGAN yang dapat dilihat pada Kode \ref{lst:discriminatorimpl}.
	
	\begin{lstlisting}[
		language=python,
		label={lst:discriminatorimpl},
		caption={Implementasi \textit{Discriminator} PatchGAN},
		xleftmargin=1em
		]
def Discriminator():
	# Input 1: Citra Artefak (Kondisi)
	inp = tf.keras.layers.Input(shape=[256, 256, 3], name='input_image')
	
	# Input 2: Citra Target (Bersih atau Hasil Generator)
	tar = tf.keras.layers.Input(shape=[256, 256, 3], name='target_image')
	
	# Gabungkan input (Conditional GAN)
	x = tf.keras.layers.concatenate([inp, tar]) # (bs, 256, 256, 6)
	
	# Downsampling Layers (Ekstraksi Fitur)
	down1 = downsample(64, 4, False)(x)
	down2 = downsample(128, 4)(down1)
	down3 = downsample(256, 4)(down2)
	
	# Lapisan Konvolusi dan Zero Padding
	zero_pad1 = tf.keras.layers.ZeroPadding2D()(down3)
	conv = tf.keras.layers.Conv2D(512, 4, strides=1, kernel_initializer=initializer, use_bias=False)(zero_pad1)
	batchnorm1 = tf.keras.layers.BatchNormalization()(conv)
	leaky_relu = tf.keras.layers.LeakyReLU()(batchnorm1)
	zero_pad2 = tf.keras.layers.ZeroPadding2D()(leaky_relu)
	
	# Output Layer: Matriks Validitas (Patch Map)
	last = tf.keras.layers.Conv2D(1, 4, strides=1, kernel_initializer=initializer)(zero_pad2) # (bs, 30, 30, 1)
	
	return tf.keras.Model(inputs=[inp, tar], outputs=last)
	\end{lstlisting}
	
	PatchGAN membagi citra menjadi \textit{patch-patch} kecil, misalnya $70 \times 70$ piksel dan menilai keaslian setiap \textit{patch} secara independen. \textit{Output} akhirnya adalah matriks $30 \times 30$ nilai validitas. Pendekatan ini memaksa \textit{Generator} untuk menghasilkan detail tekstur frekuensi tinggi yang tajam dan realistis di seluruh bagian gambar, tidak hanya secara global.
\end{adjustwidth}

\subsubsection{Mekanisme Pelatihan}

\begin{adjustwidth}{1em}{0pt}
	\hspace{\parindent}Mekanisme pelatihan Pix2Pix melibatkan proses optimasi dua jaringan (\textit{Generator} dan \textit{Discriminator}) secara simultan melalui mekanisme permainan \textit{min-max}. Proses ini mencakup definisi fungsi objektif (loss function) dan implementasi langkah pelatihan (training step).
	
	Pelatihan Pix2Pix menggunakan fungsi \textit{loss} gabungan untuk mengoptimalkan \textit{Generator} agar menghasilkan citra yang realistis sekaligus akurat secara struktural. Berikut adalah fungsi \textit{loss} yang digunakan:
	
	\begin{enumerate}[nosep]
		
		\item \textbf{\textit{Adversarial Loss (GAN Loss)}:} Menggunakan \textit{Binary Cross-Entropy} untuk menilai seberapa baik \textit{Generator} dapat mengelabui \textit{Discriminator} agar percaya bahwa citra hasil rekonstruksi adalah asli.
		
		\item \textbf{L1 \textit{Loss (Reconstruction Loss):}} Menghitung \textit{Mean Absolute Error} antara piksel citra hasil rekonstruksi dan citra target untuk memastikan warna dan struktur citra hasil sesuai dengan aslinya.
		
	\end{enumerate}
	
	Berikut adalah implementasi dari fungsi \textit{loss}.
	
	\begin{lstlisting}[
		language=python,
		label={lst:genlossimpl},
		caption={Implementasi Fungsi \textit{Loss Generator}}
		]
def generator_loss(disc_generated_output, gen_output, target):
	# 1. Adversarial Loss: Generator mencoba menipu Discriminator (Target = 1)
	gan_loss = loss_object(tf.ones_like(disc_generated_output), disc_generated_output)
	
	# 2. L1 Loss: Mengukur perbedaan piksel absolut dengan ground truth
	l1_loss = tf.reduce_mean(tf.abs(target - gen_output))
	
	# Total Loss dengan pembobotan LAMBDA (100)
	total_gen_loss = gan_loss + (LAMBDA * l1_loss)
	
	return total_gen_loss, gan_loss, l1_loss
	\end{lstlisting}
	
	Total \textit{loss} untuk \textit{Generator} adalah total dari kedua \textit{loss} tersebut, dengan bobot $\lambda = 100$ diberikan pada L1 \textit{Loss} untuk memprioritaskan akurasi struktur.
